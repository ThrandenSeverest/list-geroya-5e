# HeroList Windows (portable EXE)

Self-contained Electron Windows executable. No Node.js, server, account or network connection is required on the user's PC.

The bundled static client is served through a secure private Electron protocol. Saves are persisted in app userData; JSON/ZIP export opens Windows Save As; PDF uses native printToPDF.

Before deleting the application's data directory export your characters to a ZIP backup. Windows SmartScreen may warn about an unsigned EXE.
