# Adventure Mode: аудит и исправления интерфейса, 17.10.2026

Проверена main на коммите 07cbb26. Основная проблема: одинаково большие карточки для разных задач, чрезмерные диапазоны ползунков и повторение информации.

| Проблема | Изменение |
| --- | --- |
| Ползунок модификатора ±10 000, разовая поправка ±1000 | Рабочая шкала ±20; точный ввод сохранён |
| Количество кубов до 100 | Панель кубов ограничена 1–20; своя формула остаётся отдельным инструментом |
| Создание ресурса с диапазоном до 10 000 | Рабочая шкала 1–20, точный ввод сохранён |
| Предметы, КД и длительности используют одинаковую шкалу 0–100 | Предметы 0–20 (или текущий запас), бонус КД −5…5, КД 5–30, длительность эффекта 0–10 ходов; точный ввод сохранён |
| «Концентрация: нет» занимает постоянный блок | Общая панель активных состояний, эффектов, истощения и концентрации; добавление/снятие состояния из HUD |
| Проверка концентрации доступна только после применения урона | В магии поле урона слева от броска Телосложения, Сл max(10, floor(урон/2)); бонус героя и режим броска учитываются |
| Зелья представлены карточками с лишними кнопками | Четыре кнопки с разными размерами флакона, формулой и количеством; отсутствие запаса блокирует использование |
| Стандартное зелье повторяется большой карточкой расходника | Исключено из общего списка быстрых расходников; четыре кнопки доступны прямо в действиях |
| Большие отступы, заливки, заголовки и пустой блок «Атаки» | Компактные панели, спокойные контурные кнопки, заголовок атак без отдельной карточки |
| Фильтры магии занимают по полной строке; кнопки ячеек переносятся | Гибкие фильтры и явная сетка счётчиков |

Состояния и ярость — игровые отметки; автоматизацию их механических последствий эта правка не добавляет. Произвольные эффекты добавляются на вкладке «Герой». Ручная проверка концентрации не наносит урон повторно; при совпадении урона снимает одну ожидающую проверку, провал завершает концентрацию.

Проверки: TypeScript, 164 теста правил, production build, браузерная проверка запаса зелий и лечения, диапазона кубов, Сл для 0/21/50 урона, мобильной ширины 390 px и ошибок JavaScript. Десктоп проверен при ширине 1440 px.
