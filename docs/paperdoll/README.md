# Альтернативные иконки Paperdoll

Ветка: `feat/paperdoll-icons`. Поясные портреты для 60 рас и 13 классов.

Тестовая полная версия: https://thrandenseverest.github.io/list-geroya-5e/assets/paperdoll/

Workflow `paperdoll-pages.yml` публикует только `assets/paperdoll/` в `gh-pages`.
Главная страница, её сборка и ветка `main` не заменяются. Каталог находится
внутри `assets`, который основной издатель сохраняет при обновлении сайта.
LocalStorage и SessionStorage тестовой версии используют префикс
`herolist-paperdoll-v1:`; сохранения основной версии не изменяются.
Галерея слоёв доступна по `paperdoll/preview.html` относительно тестового адреса.

Локальная проверка той же сборки:

```sh
HEROLIST_PAGES=1 NEXT_PUBLIC_BASE_PATH=/list-geroya-5e/assets/paperdoll npm run build
node scripts/paperdoll/prepare-preview.mjs
```

При выборе расы появляется основа в нейтральной одежде. При выборе класса
на неё накладывается одежда этого класса. Карточки классов, сводка героя
и сохранённые персонажи используют ту же выбранную расу.
Пользовательские PNG Homebrew сохраняют приоритет.

## Единая вёрстка

| Параметр | Значение |
| --- | --- |
| Исходный атлас | 1536 × 1024, 3 столбца × 2 строки |
| Порядок нарезки | Слева направо, затем следующая строка |
| PNG каждого слоя | 512 × 512, RGBA |
| Поза | Анфас, поясной портрет, руки опущены |
| Прямоугольник одежды | x=20, y=242, ширина=472, высота=270 |
| Порядок слоёв | Основа → одежда класса → лицо/борода расы |
| Большая основа | Коэффициент ширины 1.00 |
| Обычная основа | Коэффициент ширины 0.88 |
| Маленькая основа | Коэффициент ширины 0.72 |

Категории описывают силуэт иконки, не игровой размер по правилам D&D.
Локаты, голиафы и локсодоны относятся к большой основе; эльфы и гитьянки —
к обычной; полурослики, феи и гномы — к маленькой. Полная таблица находится
в `public/paperdoll/manifest.json`.

Это **поясная** система: кентавр сохраняет расовое лицо, но его лошадиная
половина не изображается. Крылья и дополнительные руки также находятся
вне портрета. Одежда класса — визуальное оформление, она не меняет КД,
инвентарь, владения или правила персонажа.

Независимая генерация не обеспечивает точность координат сама по себе.
Скрипт измеряет прозрачные границы одежды и приводит её к общей зоне.
Для рас используются закреплённые координаты воротника `DOCKS`.
Одинаковое преобразование ширины применяется ко всем слоям категории.
Нейтральная основа использует тот же шаблон одежды; лицо, борода и хобот
перекрывают воротник отдельным передним слоем.

## Содержимое

- `sheets/`: 10 исходных атласов рас и 3 атласа одежды, по 6 элементов.
- `generation.json`: полные промпты; встроенная генерация изображений.
- `race-order.json`: соответствие 60 рас ячейкам атласов.
- `../../public/paperdoll/bases/`: 60 основ.
- `../../public/paperdoll/heads/`: 60 передних слоёв лица и шеи.
- `../../public/paperdoll/overlays/`: 39 вариантов одежды, 13 × 3 категории.
- `../../public/paperdoll/preview.html`: галерея со сменой класса,
  фильтром категории, направляющими и просмотром только одежды.
- `../../public/paperdoll/review.jpg`: обзор 60 собранных сочетаний.

Третий атлас одежды содержит изобретателя, нейтральную одежду и четыре
запасных варианта. Запасные варианты сохранены в исходнике, интерфейс
использует 13 основных классов.

## Повторная нарезка и проверка

Из корня репозитория, Python с установленным Pillow:

```sh
python scripts/paperdoll/prepare.py
python scripts/paperdoll/verify.py
node node_modules/typescript/bin/tsc --noEmit --incremental false
npm run build
```

Для отдельного просмотра галереи:

```sh
python -m http.server 8080 --directory public
```

Откройте `http://localhost:8080/paperdoll/preview.html`.
Проверка файлов контролирует 159 прозрачных PNG и наличие слоёв
для всех 780 сочетаний. Она не подменяет визуальную проверку портретов.
