# Классический лист и аудит заклинаний

## Реализовано в экспериментальной ветке
- Новый альтернативный трёхстраничный A4-макет, построенный по загруженному образцу D&D 5e: основные параметры, сведения о персонаже, таблица заклинаний 0–9 кругов.
- Переключатель между существующим и классическим листом. Данные персонажа общие, изменения экспорта и хранилища не требуются.
- Перенос заклинаний, не вмещающихся в таблицу, на дополнительные страницы.
- Более гибкая компоновка печатных карточек заклинаний в зависимости от длины описания, ссылка на источник.
- У заклинания «Искусная острота» (Silvery Barbs) восстановлены основные правила реакции, переброса и эффекта преимущества, а также параметры применения.

## Что НЕ следует считать завершённым
- **Книжный дословный текст всех заклинаний не импортирован.** Файл DnD_character_list.pdf содержит только макет листа персонажа, а не книгу заклинаний. Исходный импортированный каталог содержит 514 записей со средним объёмом описания около 358 символов: полнота и точное соответствие печатному изданию для каждой записи не подтверждены.
- 514 карточек требуют сверки по надлежащему источнику текста, с сохранением всех эффектов, ограничений, вариантов, компонентов и усиления на высших кругах.
- Для полного дословного импорта нужны правомерно предоставленные пользователем тексты или разрешённые к распространению источники. Нельзя маскировать краткое изложение под точную книжную цитату.
- Проверка сборки, печати A4 на разных браузерах, мобильной вёрстки и мультиклассовой магии ещё не выполнена. Не сливать в main без этих проверок.

## Контроль качества
1. Проверить TypeScript и сборку приложения.
2. Печать A4: ровно три основные страницы плюс продолжения только при переполнении.
3. Сопоставить расположение полей с тремя страницами пользовательского PDF, проверить долгие имена и мультикласс.
4. Прогнать карточки коротких и длинных заклинаний на отсутствие обрезания.
5. Для **каждого** заклинания проверить все игровые условия: накладывание, дальность, компоненты, длительность, концентрацию, спасброски, урон, варианты, усиление ячейкой и ограничения.
