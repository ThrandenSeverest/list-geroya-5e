# HeroList 1.2.1 — готовая папка для хостинга

1. Остановите сайт.
2. Скопируйте **всё содержимое этой папки** поверх текущей папки HeroList с объединением каталогов и заменой совпадающих файлов. Саму текущую папку перед копированием не удаляйте.
3. Запустите сайт снова тем же способом, которым он запущен сейчас.

Готовый `dist/` уже собран. Ничего пересобирать, устанавливать или мигрировать не требуется.

Папка содержит файлы приложения: `app/`, `backend/`, `deployment/`, `public/`, `scripts/`, конфигурацию и полный `dist/`.

В комплекте **нет** рабочего `.env`, SQLite/database-файлов, `backend/data/`, аккаунтов, персонажей, сохранений, `uploads/` и резервных копий. Существующие данные сервера останутся на месте, если выполнить копирование поверх текущей папки, а не удалять её целиком.

Версия квиза: 1.2.1. В прохождении 17 постоянных вопросов и 1–6 адаптивных уточнений (всего 18–23). Удалены вопрос с мостом, первые два вопроса с новичками, Q26, Q27, Q32, Q42, Q43, Q49, Q50 и вопрос о волшебной вещи с неудобством.
