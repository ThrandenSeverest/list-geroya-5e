# HeroList — обновление 1.2.1

Это минимальная папка обновления существующего production-хостинга с версии 1.2.0. Backend, база данных и пользовательские файлы не менялись.

1. Скопируйте папку `dist/client/` отсюда в существующую `dist/client/` с заменой файлов.
2. Удалите из существующей `dist/client/` пути, перечисленные в `DELETE_FROM_DIST_CLIENT.txt`.
3. Перезапустите приложение и обновите страницу с очисткой кэша.

Не заменяйте и не удаляйте `.env`, SQLite/database-файлы, `backend/data/`, аккаунты, сохранения, `uploads` и резервные копии.

Обновление добавляет новый квиз из 18–23 вопросов: 17 обязательных сбалансированных вопросов и 1–6 адаптивных уточнений. Исключённые вопросы удалены из банка. Спорные результаты учитывают повторные сигналы и основную характеристику класса; подраса эльфа подбирается под класс.
