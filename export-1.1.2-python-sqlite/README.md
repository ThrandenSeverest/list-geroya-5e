# HeroList — export 1.1.2

Отдельная копия текущей рабочей версии HeroList для внедрения выбора между Legacy-расами и их версиями из `Mordenkainen Presents: Monsters of the Multiverse` (MPMM).

Основа папки скопирована из актуальной `export-1.1.0-python-sqlite` без повторной ручной сборки и без изменений существующей версии. Backend, авторизация, база данных, мультиклассирование, подклассы, заклинания, PDF и остальные несвязанные части сохранены как есть.

## Что изменено

- Для рас, переизданных/изменённых в MPMM, добавлен явный выбор источника правил.
- Пример: гоблин можно выбрать как `Гоблин — Мордекайн` или `Гоблин — Volo`.
- Для MPMM-версий варианты `+2/+1` и `+1/+1/+1` показаны отдельными пунктами — это намеренное UI-решение для наглядности, а не разные официальные версии расы.
- Добавлены Legacy-варианты VGM, MTF, SCAG, EEPC/PoA, ERLW, GGR, MOT, WBW и The Tortle Package там, где они относятся к соответствующей расе.
- Старые сохранения, где MPMM-раса уже хранилась как `raceVariant: "base"`, продолжают открываться как MPMM-версия и не требуют миграции.
- Существующие ID старых вариантов аасимара, дженази и шифтера сохранены, чтобы не ломать созданных персонажей.

## Как реализовано

Исходный `app/characterRules.ts` сохранён без изменений как `app/characterRules.base.ts`. Новый `app/characterRules.ts` переиспользует всю прежнюю логику и переопределяет только данные и функции, относящиеся к расам. Это сделано специально, чтобы не копировать и не редактировать заново большой файл с подклассами, заклинаниями и прочими правилами.

## Production dist

`dist/` пересобран с нуля из исходников 1.1.2 через production-команду `vinext build` после успешной проверки каталога подклассов. Это уже новая сборка с Legacy/MPMM вариантами рас и сохранёнными предыдущими исправлениями PDF и владений/компетентности.

Для обновления существующего production-хостинга используйте отдельную минимальную папку `hosting-update-1.1.2/`: в ней лежит только новый `dist/` и инструкция. Backend в этом обновлении не менялся и намеренно не дублируется.

Не заменяйте `.env`, SQLite/database-файлы, `backend/data/`, пользовательские сохранения, uploads и резервные копии при переносе этой версии на существующий хостинг.
