# HeroList — готовая папка обновления 1.3.0

В папке находятся готовая production-сборка, исходники приложения, backend и файлы запуска. Базы данных, `.env`, аккаунтов, сохранений и пользовательских загрузок здесь нет.

## Обновление хостинга

1. Остановите приложение.
2. Скопируйте содержимое этой папки в каталог установленного HeroList с заменой файлов. Папку `dist` замените целиком, чтобы на сервере не остались старые файлы сборки с хешированными именами.
3. Не удаляйте и не заменяйте существующие `.env`, SQLite/database-файлы, `backend/data/`, `uploads/`, сохранения и резервные копии.
4. Один раз выполните `cd backend && alembic upgrade head` с прежним `DATABASE_URL`.
5. Запустите приложение прежней командой или службой и обновите страницу с очисткой кэша.

Версия сайта — **1.3.0**. Добавлены копирование персонажей, итоговая проверка, расширенные фильтры заклинаний и личная аккаунтная библиотека хоумбрю.

Миграция создаёт отдельную таблицу хоумбрю и не изменяет существующие аккаунты или персонажей.
