# HeroList GitHub test

Эта папка предназначена для тестового запуска без production backend.

Важно: для GitHub Pages нужен статический экспорт. Если текущая сборка использует серверные маршруты Next.js/FastAPI, Pages напрямую её не запустит. Для локального теста используйте обычный Next.js dev/build режим.

Production Telegram/External Auth в этой тестовой папке не должен использоваться.
