# HeroList — готовая папка обновления 1.4.0

В папке находятся готовая production-сборка, исходники приложения, backend и файлы запуска. Базы данных, `.env`, аккаунтов, сохранений и пользовательских загрузок здесь нет.

## Обновление хостинга

1. Остановите приложение.
2. Скопируйте содержимое этой папки в существующий каталог HeroList с заменой файлов. Сам каталог приложения предварительно не очищайте.
3. Папку `dist` замените целиком, чтобы на сервере не остались старые файлы сборки с хешированными именами.
4. Сохраните существующие `.env`, SQLite/database-файлы, `backend/data/`, `uploads/`, сохранения и резервные копии: в пакете их нет, заменять или удалять их не нужно.
5. Запустите приложение прежней командой или службой и обновите страницу с очисткой кэша.

Для обновления 1.4.0 не требуются пересборка на сервере, установка новых зависимостей или миграция базы данных.

Версия сайта — **1.4.0**. Добавлен добровольный режим «Создать с обучением»: 11 вводных окон, контекстная справка по терминам, безопасный выход из обучения и три итоговых вопроса о созданном герое. Обычное создание работает без обучающих окон.

Обновление 1.4.0 не меняет JSON-схему персонажа, базу данных, аккаунты и существующие сохранения.
