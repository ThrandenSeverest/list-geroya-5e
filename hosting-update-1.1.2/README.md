# HeroList — hosting update 1.1.2

Эта папка предназначена только для обновления уже работающего production-хостинга HeroList.

## Что заменить

Замените на сервере существующую папку `dist/` папкой `dist/` из этого обновления.

Новый `dist` собран из `export-1.1.2-python-sqlite` командой production-сборки `vinext build` после успешной проверки каталога подклассов.

## Что НЕ трогать

Не заменяйте, не удаляйте и не очищайте:
- `.env`;
- SQLite/database-файлы;
- `backend/data/`;
- пользовательские сохранения;
- `uploads/` и загруженные пользователями файлы;
- резервные копии;
- настройки авторизации и секреты.

Backend в 1.1.2 относительно предыдущего hosting-пакета не менялся, поэтому в эту папку он намеренно не дублируется.

В обновление входят новые Legacy/MPMM варианты рас, при этом ранее внесённые исправления PDF и владений/компетентности сохранены.
