# HeroList — обновление 1.2.0

Минимальный пакет обновления относительно `hosting-update-1.1.2`: здесь только изменённые клиентские файлы и список устаревших файлов, которые требуется удалить.

1. Скопируйте `dist/client/` из этой папки в существующую `dist/client/` с заменой файлов.
2. Удалите из существующей `dist/client/` все пути из `DELETE_FROM_DIST_CLIENT.txt`.
3. Перезапустите приложение и обновите страницу с очисткой кэша.

Не трогайте `.env`, SQLite, аккаунты, сохранения, `uploads` и backend.

Добавлены главное меню, Point Buy / стандартный набор 15, 14, 13, 12, 10, 8 и «Какой из тебя герой?» — 20 вопросов с готовым персонажем уровня 1–20.
