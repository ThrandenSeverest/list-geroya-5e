# HeroList — обновление 1.2.2

Скопируйте содержимое папки `dist/client` поверх существующей папки `dist/client` с заменой файлов, затем перезапустите приложение.

Папка содержит только изменённую клиентскую сборку: главное меню, переход к квизу, панель «Отдельное спасибо» и изображения. База данных, `.env`, аккаунты, сохранения и загрузки в обновление не входят и не заменяются.
