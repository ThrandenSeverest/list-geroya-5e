# HeroList 5e

Каноническая production-версия конструктора персонажей D&D 5e 2014. `main` содержит одну актуальную копию исходников; готовые пакеты хостинга создаются GitHub Actions и прикладываются к релизам.

## Локальная проверка

```bash
npm ci
npm run test:rules
npm run build

cd backend
python -m pip install -r requirements.txt
python -m pytest
```

## Обновление хостинга

1. Скачайте `HeroList-hosting-<version>.zip` из GitHub Release.
2. Остановите приложение.
3. Замените runtime-файлы содержимым архива.
4. Не удаляйте и не заменяйте `.env`, `backend/data/`, SQLite-файлы, `uploads/` и `saves/`.
5. Выполните Alembic-миграции и перезапустите приложение.

Архив релиза содержит свежий `dist/`, backend и deployment-файлы, но никогда не содержит секреты или пользовательские данные.

## Правила репозитория

- Новые версии оформляются тегами и релизами, а не копиями `hosting-update-*` или `export-*`.
- `dist/`, кэши, базы и `.env` не коммитятся.
- Полные пользовательские данные не пишутся в логи.
- Описания правил хранятся централизованно и не копируются в сохранения персонажей.
