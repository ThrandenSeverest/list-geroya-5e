# HeroList 5e

Каноническая production-версия конструктора персонажей D&D 5e 2014. `main` содержит одну актуальную копию исходников; готовые пакеты хостинга создаются GitHub Actions и прикладываются к релизам.

## Локальная проверка

```bash
npm ci
npm run test:rules
npm run build

cd backend
python -m pip install -r requirements.txt
python -m pytest
```

## Обновление хостинга

Развёртывание выполняется из содержимого `main`. Полная инструкция со
списками удаляемых файлов и сохраняемых пользовательских данных находится в
[`HOSTING_UPDATE.md`](HOSTING_UPDATE.md).

Критически важно сохранить `.env`, фактическую SQLite-базу из
`DATABASE_URL`, `backend/data/`, `uploads/` и `saves/`. Старые
build-каталоги и каталоги-снимки версий, наоборот, нужно удалить.

## Правила репозитория

- Новые версии оформляются тегами и релизами, а не копиями `hosting-update-*` или `export-*`.
- `dist/` коммитится вместе с исходниками после сборки и очистки через `scripts/sanitize-committed-dist.py`. Кэши, базы и `.env` не коммитятся.
- Полные пользовательские данные не пишутся в логи.
- Описания правил хранятся централизованно и не копируются в сохранения персонажей.


### Мастерская Homebrew: способности и ресурсы

В «Развитие и способности» выберите уровень. Сводка «Всё развитие от 1 до 20 уровня» показывает класс целиком. Карточки способностей раскрываются по отдельности. Внутри карточки выберите действие: изменить показатели, ограничить применения, добавить атаку, дать выбор, дать заклинания или добавить действие. ID, карта связей и JSON остаются в дополнительных настройках.

Для числового значения можно выбрать постоянное число, бонус мастерства, уровень класса, модификатор характеристики или кости. Произвольные формулы по-прежнему доступны и не переписываются при открытии. У ресурса можно задать улучшения по уровням: новый максимум и/или способ восстановления. Действие может расходовать ресурс другой способности; число расходуемых применений задаётся отдельно. Бонусные заклинания редактируются внутри способности и открываются с её уровня.

Формат v2 расширен необязательными `features[].spellGrants` и `resources[].progression` (также внутри способностей). Ступень ресурса содержит `level`, необязательный `max` и необязательный `restore`. До первой ступени используются исходные поля; далее наследуется последняя доступная настройка. Старые файлы остаются действительными, идентификаторы и потраченные применения не меняются. На сервере поля сохраняются целиком; миграция базы для этого не нужна.

Это расширение не означает полного равенства всех Homebrew-классов встроенным: отдельной работы требуют динамические состояния, превращения, некоторые подклассовые системы и единый источник классовой механики. Ограничение сервера 32 КиБ на элемент пока сохранено. Не импортируйте текст класса как якобы полностью автоматизированную копию: проверяйте эффекты, ячейки, выборы и ресурсы на нужных уровнях.
